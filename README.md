# AWS Student Community Day 2026 (Pune Edition)

> The official frontend web platform for **AWS Student Community Day 2026 Pune**, inspired by architectural editorial brutalism and variable cloud typography.

## Event Brief
- **Date:** 27 December 2026 (09:00 AM – 04:00 PM IST)
- **Venue:** Seasons 24 Banquet & Conventions, Wagholi, Pune, Maharashtra 412207, India
- **Capacity:** 300 Student Builders
- **Ticketing & Registration:** Powered by KonfHub

## Key Features & Highlights
- **(01) Variable Cloud Typography Playground:** Interactive kinetic variable type specimen engine.
- **(02) Cloud Checkpoints:** 5 architectural stations from localhost `127.0.0.1` to global cloud intelligence.
- **(03) Classified Keynotes & Breakouts:** Teaser telemetry dossiers across GenAI, Serverless, and Kubernetes.
- **(04) Pass Customization Rig:** Interactive digital badge generator with variable type and telemetry hash export.
- **(05) Physical Perforated Ticket Stub:** KonfHub direct integration and delegate access pass.
- **(06) Tactical Radar & Wayfinding:** High-precision SVG vector map of Wagholi with custom zoom engine and authentic landmarks.
- **(07) Attendee Protocols & FAQ:** Interactive accordion field guide and cloud sponsor matrix.

## Development & Build

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Run Dev Server
```bash
npm run dev
```
Runs locally at `http://localhost:3005/`.

### Production Build
```bash
npm run build
```
Generates production bundle in `/dist`.
